# SkyproWallet

Веб-приложение для учета личных финансов. Позволяет отслеживать доходы и расходы, управлять транзакциями и просматривать аналитику трат по категориям и периодам.

## Основные функции
* Регистрация и авторизация пользователей, выход из аккаунта.
* Добавление, просмотр и удаление транзакций.
* Фильтрация и сортировка операций.
* Аналитика расходов и доходов с графиками за выбранный период.
* Адаптивный интерфейс для компьютеров, планшетов и смартфонов.

* HTML5, CSS3 (адаптивная верстка)
