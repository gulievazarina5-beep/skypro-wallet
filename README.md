# SkyproWallet

Индивидуальный проект по разработке веб-приложения для управления личными финансами.

## Технологический стек
* React 18
* Vite
* React Router DOM 6
* Axios

## Инструкция по развертыванию приложения

### 1. Клонирование репозитория
```bash
git clone <ссылка_на_ваш_репозиторий>
cd skypro-wallet
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск проекта в режиме разработки
```bash
npm run dev
```

### 4. Проверка кода линтером
```bash
npm run lint
```

## Структура выполненных работ (Спринт 1)
* Инициализирована базовая архитектура проекта на Vite + React.
* Настроен декларативный роутинг страниц (`/auth`, `/main`, `/analytics`).
* Сверстана адаптивная страница авторизации и регистрации с переключением режимов.
* Создан каркас главной страницы с формой добавления транзакций и историей операций.
* Реализована страница аналитики расходов со встроенной сеткой календаря и диаграммами по категориям.
